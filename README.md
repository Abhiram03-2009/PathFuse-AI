# Resumate AI (original source)

The original JavaScript version of this app, written in spring 2025 before it was uploaded to Lovable in June 2025 and rewritten in TypeScript. The current app lives on `main` as PathFuse AI. This branch is kept for reference and contains no API keys.

The original file `src/aiService.js` contained a hard-coded OpenAI API key. It has been replaced with the placeholder `YOUR_OPENAI_API_KEY` here, and that key should be treated as revoked.
